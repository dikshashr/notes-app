# Purple Notes 📝
 A note taking web app, allows user to take notes using Markdown editor



## Features 🧩
* **User Accounts & Profiles:** Create a personal account to keep your notes private and secure.
* **Cloud-Synced Storage:** Your notes are saved to a secure database in the cloud. Access them from any device, anywhere.
* **Markdown support:** Write and preview notes using full Markdown syntax
* **Theme:** Toggle between specialized themes designed for focus
* **Responsive Design**

## Tech Stack 🚀
* **Front-end**
  * HTML
  * CSS
  * Javascript

* **Back-end**
  * Node.js
  * Express.js
 
* **Database**
  * JWT
  * MongoDB

## 🛠️ Installation
1. Clone the repositary
 ```
https://github.com/dikshashr/notes-app.git
cd notes-app
 ```
2. Install Dependencies
```
npm install
```
3. Run the Project
```
npm start
```
